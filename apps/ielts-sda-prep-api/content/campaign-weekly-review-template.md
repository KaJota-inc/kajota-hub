# Weekly review template — every Sunday, 30 minutes

*Sunday is the Sanguine win-loop AND the Melancholic audit. Both voices get
served. The parking lot gets drained.*

## 1. Scorecard (5 min)

Open the workbook's Weekly Scorecard sheet AND `performance-log.md`.
Mark the week's exit gate as **Done / Partial / Missed**.

- Week N exit gate: *paste from workbook*
- Status this week: ___
- Blockers that moved into the open: ___
- Blockers that closed this week: ___ *(celebrate — Sanguine beat)*

## 2. Risk register pass (5 min)

Open `risk-register.md`. For each Open risk:
- Did any mitigation progress this week? Update the status line + date.
- Any risk past its review date with no movement? **Flag and escalate** in
  the "next-week correction" section below.
- Any risk now Closed? *Celebrate in the Sanguine beat section.*

## 6. Parking lot drain (5 min)

Pull every parking-lot entry from the week's daily files.

For each: **Act on it next week** (add to Monday) / **Defer** (move to a
future week) / **Discard** (admit it was a distraction).

- Parking-lot item 1: [act/defer/discard] because ___
- Parking-lot item 2: [act/defer/discard] because ___
- Parking-lot item 3: [act/defer/discard] because ___

**Melancholic rule**: a parking-lot item kept for three weeks running
without being acted on gets forcibly discarded. If it was really worth
doing, it would have been pulled by now.

## 7. Weakest domain of the week (3 min, Melancholic)

Open `performance-log.md` and compute the lowest average confidence domain
across the week.

- Weakest domain: ___
- Why (one honest sentence): ___
- Next week's specific recovery: ___ (one concrete action, not "study harder")

## 8. Next-week correction (3 min)

The purpose of this file is *correction*, not just reflection. Name the
single most important thing to change next week — not add, change.

- One thing I will **stop** doing: ___
- One thing I will **start** doing: ___
- One thing I will **keep** doing (because it worked): ___

## 9. Supervisor pipeline sweep (2 min)

Open `supervisors/*.md`. For each shortlisted lead:
- Any status change this week? Append a row to the Status Timeline table.
- Any next-action date overdue? Decide: send today, send Monday, deprioritise.

Imperial personal or research statement. The GenAI rule applies permanently.
If you drafted statement text this week, it was in your own words, in your
own file, outside this folder.
