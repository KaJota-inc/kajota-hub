## 🚨 Compliance box — re-read on each statement day

Imperial's PhD guidelines explicitly require the **personal statement (1–2 pages) and research statement (3–4 pages) to be written by the applicant without GenAI help**. This workspace is planning scaffolding — fit notes, methodology prompts, source checklists, DSA/SD artefacts, mock-defence banks, drill templates, outreach drafts. **Imperial statement text comes from your own keystrokes, always.** The York one-page statement has no equivalent published rule; apply the same discipline anyway.

## Three MELSAN workflows govern each day

Reference by name — defined in full at [`workflows/00-melsan-operating-system.md`](workflows/00-melsan-operating-system.md) and in the IELTS prep app's materials at [`~/Documents/ielts-sda-prep/materials/15-melsan-delivery-workflows.md`](../ielts-sda-prep/materials/15-melsan-delivery-workflows.md).

- **MELSAN-Launch** (morning, 20 min) · four acceptance tests read aloud, sources staged, flagship win written.
- **MELSAN-Execute** (per block) · phone off, 25/5 Pomodoro inside, halfway self-check, immediate artefact save, one-sentence ship log.
- **MELSAN-Close** (evening, 25 min) · four-sentence ship log, honest error log, tomorrow's acceptance tests + flagship win queued.
